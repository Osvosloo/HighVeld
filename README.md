# Highveld Cultivated Wellness

React + Vite site for the health consultancy at Robin's Corner Centre, Robindale, Randburg.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Hours on the site follow the Google listing: 08:00–20:00. Confirm Sunday hours with the shop if they differ.
